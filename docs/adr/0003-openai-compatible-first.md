# OpenAI 兼容协议为第一公民，首个落地后端是 DeepSeek

2026-10-02

v0 把 Anthropic 原生协议放在第一优先级，账号一封，整个项目就失去了"能跑"的证词——而当时已经写好的 DeepSeek 后端，反而一次都没被真机验证过。因此本轮把**协议层的第一公民定为 OpenAI 兼容**，第一个真实落地的 provider 是 **DeepSeek**（已有 key、国内可直连），Kimi 作为同协议下的第二个选项；Anthropic 原生协议降为可选的第三个实现，不阻塞任何里程碑。

## Considered Options

- **Anthropic 原生优先**：协议细节更值得学，但可用性由第三方账号决定，v0 已经栽过。
- **双协议同时落地**：学习面最广，但会拖慢 v1.0，而 v1.0 的瓶颈是"跑通"而不是"协议覆盖"。
- **OpenAI 兼容优先（选它）**：今天就能跑，且覆盖面最广。

## Consequences

- 统一消息模型必须能翻译到至少两种方言，翻译工作留在 provider 一侧。
- 推理类附加字段（思考内容等）不进统一事件流，v1.0 一律忽略。
- 换 provider 不需要动主循环——这也是"能跑"这件事不再依赖单一账号的保证。
