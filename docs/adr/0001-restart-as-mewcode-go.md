# 重启为独立仓库 mewcode-go，v0 只作对照

2026-10-02

v0（`mewcode`，2026-06）在一次两天冲刺里产出了完整骨架——七个包、六个工具、三档权限、两个后端、TUI、四份文档——但**从未用真实模型跑通过一次**（C8/T11 全空），随后因 Anthropic 账号被封而停摆。把一个从未被验证过的骨架当底座做增量改造，等于把它里面所有未经验证的假设一起继承下来，所以本轮**重启**：新建 public 仓库 `mewcode-go`，v0 归档改名 `mewcode-v0` 只读保留，日后做对照。

## Considered Options

- **在旧仓库续写**：省事，但会继承未经证实的假设，且无法区分"v0 的债"与"v1 的选择"。
- **同仓库 orphan 分支清空历史**：历史干净，但 GitHub 主页看起来仍是一个项目。
- **新建仓库（选它）**：主页上自然呈现 v0 → v1 两段叙事，对求职是"迭代过一版"的证据，而不是"放弃了一个项目"。

## Consequences

- v0 的四件套文档（spec/plan/tasks/checklist）**不复用**，只作对照素材。
- 版本阶梯固定为：v1.0 = 课程全部章节落地 + 真机证据 + 分歧笔记；v1.1 = 自研 web 面（Go HTTP + SSE + 浏览器界面）。web 面**不提前**，它依赖一个真能跑的内核。
- public 仓库里**不放课程的正文与课程代码**；仓库只承载我方实现与我方笔记。
- 真机证据与审计证据（见 ADR-0002）是公开的推进记录，v0 的复盘也一并公开。
